تنظیمات موتور هوش مصنوعی

اتصال اختیاری به یک API سازگار با قالب OpenAI.
برای استفاده از مدل آنلاین باید یک سرویس یا سرور API در اختیار داشته باشی. کلید API در این نسخه فقط تا زمان بازبودن صفحه در حافظه فرم می‌ماند و ذخیره نمی‌شود. استفاده از سرویس‌های پولی ممکن است هزینه داشته باشد. هیچ سرویس آنلاینی به‌صورت پیش‌فرض فعال نیست.
برای حریم خصوصی، از واردکردن اطلاعات حساس در سرویس‌های ناشناس خودداری کن. اتصال مستقیم مرورگر به بعضی APIها ممکن است به‌دلیل CORS مسدود شود؛ راه‌حل اصولی، یک واسط امن سمت سرور است.
